# Análisis de Pingüinos

Proyecto de ciencia de datos para analizar un conjunto de datos sobre pingüinos.

## Instrucciones para configurar el entorno de desarrollo

1. **Crear el entorno virtual:**
   ```bash
   python -m venv .venv


2. **Activar el entorno virtual**
En windows (PowerShell):
.venv\Scripts\Activate.ps1

En Windows (CMD):
.venv\Scripts\activate.bat

En macOS / Linux:
source .venv/bin/activate

3. **Instalar las dependencias**
pip install -r requirements.txt

El entorno quedará configurado exactamente con las librerías (pandas, matplotlib, seaborn) y sus respectivas versiones fijadas.
